# 🛍️ Retail Sales Analytics Dashboard (SQL | Excel | Power BI)

## 📌 Project Overview

This project demonstrates an end-to-end Retail Sales Analytics solution using SQL, Microsoft Excel, and Power BI.

The project includes:
- Data Cleaning in Excel
- SQL Data Analysis
- Interactive Power BI Dashboard
- Business KPI Analysis
- Data Modeling (Star Schema)
